# Relaid

**Run and control local AI agents from anywhere.**

Relaid is a multi-platform system that lets you securely interact with AI agents running on your local machine — from anywhere, using a mobile app. Built on ACP (Agent client protocol) for centralized agent communication.

> ⚠️ Early prototype — expect rough edges. Contributions welcome!

## Features

- **Projects** — Organize and manage your agent sessions by project
- **Git Integration** — View branches, commits, and diffs without leaving the app
- **File Mentions** — Reference files directly in your prompts
- **Diff Viewer** — Inspect code changes inline
- **Parallel Sessions** — Run multiple sessions concurrently
- **Themes** — Customize the look and feel
